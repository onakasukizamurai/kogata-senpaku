# 小型船舶免許の蛇行練習

小型船舶操縦士の実技「蛇行」をイメージした、ブラウザ向けの無料操船練習です。ブイを左右交互に通過して、試験形式の感覚を身につけられます。

**公開ページ:** https://onakasukizamurai.github.io/kogata-senpaku/

※ 正式な試験コース寸法や採点基準の完全再現ではありません。ハンドル感覚と通過順の練習用です。

## モード

- **３ブイコース（試験の形式）** … ブイ3本を通過して採点
- **エンドレスコース** … 失敗するまで続き、進んだ距離を競う

## 起動方法

1. 上記の公開ページを開く、または [`index.html`](index.html) をブラウザで開く
2. コースを選んでスタート

## 操作

| 操作 | 方法 |
|------|------|
| 操舵 | 画面右のハンドルをドラッグ、または `←` `→`（`A` `D`） |
| スロットル | スライダー、または `↑` `↓`（`W` `S`） |
| やり直し | 「リセット」または結果画面の「もう一度」 |

## 練習の狙い

- 赤いブイを **左右交互** にかわして通過する
- 次に通る側は画面上部 HUD と、ブイ横のヒントで確認できる
- 接触・逆側通過・離れすぎは減点（３ブイコース）
