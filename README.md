# 小型船舶 蛇行練習シミュレーター

小型船舶操縦士の実技「蛇行」をイメージした、ブラウザ向けの2D操船練習です。

## 起動方法

1. [`index.html`](index.html) をブラウザで開く
2. 「練習を始める」を押す

ローカルサーバーは不要です。ファイルを直接開いて使えます。

## 操作

| 操作 | 方法 |
|------|------|
| 操舵 | 画面下のハンドルをドラッグ、または `←` `→`（`A` `D`） |
| スロットル | 左のスライダー、または `↑` `↓`（`W` `S`） |
| やり直し | 「リセット」または結果画面の「もう一度」 |

## 練習の狙い

- 赤いブイを **左右交互** にかわして通過する
- 次に通る側は画面上部 HUD と、ブイ横のヒントで確認できる
- 接触・逆側通過・離れすぎは減点

※ 試験の正式コース寸法や採点基準の完全再現ではありません。ハンドル感覚と通過順の練習用です。
